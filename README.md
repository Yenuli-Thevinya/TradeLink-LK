# TradeLink LK

A full-stack home service request platform connecting Sri Lankan homeowners with skilled tradespeople.

## Tech Stack
- **Frontend:** Next.js 14, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB + Mongoose
- **Auth:** JWT

## Features
- Post and browse service requests
- Role-based access (admin / public)
- Assign workers to jobs
- Customer feedback & star ratings
- Full CRUD with business rules

## Setup
1. `cd backend && npm install && npm run dev`
2. `cd frontend && npm install && npm run dev`
3. Add `.env` with `MONGO_URI` and `JWT_SECRET`
